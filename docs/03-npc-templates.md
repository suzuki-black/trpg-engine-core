# 3. NPC人格テンプレート

## 3.1 目的

複数のNPCをAIで動かすための「人格テンプレート」を定義し、キャラごとの一貫性を保てるようにする。

- NPCごとに **性格・口調・目的・秘密** を持たせる。
- プレイヤーとの会話で、性格がブレないようにする。
- GMから渡される「状況」「プレイヤー発言」をもとに応答を生成する前提とする。

NPCモジュールは、テンプレートを**システムプロンプト**として読み込み、可変情報（状況・プレイヤー発言）を毎ターン受け取って応答する。

---

## 3.2 NPC人格テンプレートの項目

各NPCは以下の項目で定義する。

| 項目 | 内容 |
| --- | --- |
| name（名前） | NPCの呼び名 |
| role（役割） | 立場・職能（例：村の長老、盗賊ギルドの構成員） |
| personality（性格） | 慎重、陽気、冷酷 など |
| tone（口調） | 丁寧、ぶっきらぼう、芝居がかった など |
| public_goal（表向きの目的） | プレイヤーや周囲に見せている目的 |
| hidden_goal（隠された目的・秘密） | 本人だけが知る本当の動機・秘密 |
| attitude（基本的な態度） | プレイヤーへの初期姿勢：協力的 / 中立 / 敵対的 |

`hidden_goal` は通常プレイヤーには直接明かさない。会話の判定結果や進行フラグに応じて、断片的に漏れることがある。

## 3.3 テンプレートの記述例（サンプル3体）

### NPC-1：情報屋「カラス」

## 3.4 NPC応答の方針

NPCは、プレイヤーの発言に対して以下の3軸を**性格に応じて**判断し、応答を生成する。

### (1) 情報を出すか、隠すか

- `hidden_goal` に関わる情報は原則として隠す。
- 性格が「協力的・思いやり深い」NPC（例：ミレーユ）は、表向きの情報は積極的に開示する。
- 「抜け目ない」NPC（例：カラス）は、対価や交換条件がなければ核心を出さない。
- 交渉・説得の**判定結果が成功**した場合は、普段は隠す情報を一段階多く開示してよい。

### (2) 協力するか、拒否するか

- `attitude` を初期値とし、プレイヤーの態度・進行フラグ・判定結果で増減させる。
- 敵対的・中立のNPCでも、利害が一致すれば一時的に協力する。
- 「情に弱い」NPC（例：ゴルツ）は、誠実な頼み方や弱者を守る選択に動かされやすい。

### (3) 感情的になるか、冷静でいるか

- `personality` と `tone` に従う。皮肉屋は軽口で受け流し、穏やかなNPCは冷静を保つ。
- 短気なNPC（例：ゴルツ）は侮辱や脅しに反応して感情的になりやすい。
- ただし、感情的になっても**人格の核（根は善人、約束は守る等）は維持する**。

### 一貫性を保つための原則

- NPCは常に自分の `personality` `tone` `public_goal` `hidden_goal` `attitude` に照らして応答する。
- プレイヤーの発言で人格が急変しない。態度の変化は「段階的」に表現する。
- `hidden_goal` を自分から不用意に明かさない。漏らすのは、判定成功・信頼関係の進展・物語上の必然がある時に限る。

---

## 3.5 NPCが「知らない情報」を扱うルール

NPCは全知ではない。自分が知り得ない情報は、知らないものとして振る舞う。

- **他NPCの秘密は知らない**：他NPCの `hidden_goal` や事情を、共有設定がない限り知らない。
- **未到達の章の内容は知らない**：まだ進んでいない章の出来事・真相を先取りして語らない。
- **役割の範囲外は知らない**：自分の立場・行動圏から自然に知り得ない情報（遠方の事件、専門外の知識）は把握していない。
- **知らないことを問われたら**：知ったかぶりをせず、「知らない」「分からない」と性格に沿った形で返すか、推測であると明示する。
- **判明済みでも未開示は別**：シナリオ上は真実でも、その章で未解放の情報は「知っていても話さない／話せない」として扱う（[01-architecture.md](01-architecture.md) のシナリオ管理の制約に従う）。

## 3.6 NPCの態度変化の段階（簡易3段階）

NPCの `attitude` は固定ではなく、プレイヤーの言動・判定結果・進行フラグに応じて段階的に変化する。急変はさせず、隣り合う段階を1つずつ移動させる。

| 段階 | 状態 | NPCの振る舞い |
| --- | --- | --- |
| 敵対的（Hostile） | 警戒・反発 | 情報を出さず、協力を拒む。脅威とみなせば離れる・対立する |
| 中立（Neutral） | 様子見 | 対価や理由があれば協力する。表向きの情報のみ開示 |
| 友好的（Friendly） | 信頼・協力 | 進んで協力し、`hidden_goal` の一端を漏らすこともある |

- **上昇の例**：誠実な対応、依頼の達成、交渉判定の成功 → 1段階上がる。
- **下降の例**：裏切り、侮辱、交渉判定の大失敗 → 1段階下がる。
- 1ターンで2段階は飛ばさない。変化はセリフのトーンに段階的に反映する。

---

## 3.7 NPCモジュールの返却形式

NPCモジュールが返すのは「**セリフ ＋ トーン**」のみとする（[01-architecture.md](01-architecture.md) と一致）。

- **セリフ（line）**：そのNPCの発言テキスト。口調（tone項目）を反映する。
- **トーン（tone/emotion）**：その発言時の感情・態度の指定。例：冷静 / 苛立ち / 友好的 / 警戒。

返却に含めないもの：

- 地の文・場面描写（GMが担当）。
- フラグ更新・判定要求・章進行などの進行制御（NPCは行わない）。
- 他NPCのセリフや、自分が知らない情報。

返却イメージ：

```
line: 「タダ、ねえ。坊や、この街じゃ言葉も酒も先払いだよ」
tone: 皮肉・突き放し
```

GMはこの「セリフ＋トーン」を受け取り、地の文に統合して物語を進める。

---

## 3.8 補足：本書はフィクション設定である

本書のNPCは、TRPGを面白くするための**フィクションのキャラクター設定**である。「隠された目的」「敵対的」「脅し」などの記述は、物語上の緊張感を生むためのゲーム要素であり、現実の行為を意図するものではない。
