# 5. 最初のシナリオの骨格

## 5.1 目的

テストプレイ用の短めのシナリオを用意し、TRPGエンジンの動作確認に使えるようにする。

- プレイ時間の目安：1〜2時間程度。
- 章構造を持つ（導入 → 道中 → 探索 → 対決 → 結末）。
- プレイヤーの選択によって、少なくとも2〜3通りの結末に分岐する。

---

## 5.2 シナリオタイトル

**「忘れられた祠（ほこら）の灯」**

---

## 5.3 世界観の簡単な説明

中世風ファンタジー。深い森のふもとにある小さな村「リンデン」と、その近くにある古い遺跡「忘れられた祠」が舞台。

- 村は平穏だが、近頃、夜になると祠の方角から青白い光が漏れ、家畜が怯えるようになった。
- 村人は「祠に災いが棲みついた」と恐れている。
- プレイヤーは村を訪れた流れの冒険者で、村長からこの異変の調査を依頼される。

汎用的で扱いやすく、GMが即興補完しやすい設定にしてある。

---

## 5.4 章構造

各章について「章の目的」「主要イベント」「想定されるプレイヤー行動」を整理する。

### 第1章：導入 — 村での依頼

- **章の目的**：依頼を受注し、祠についての情報を集める。
- **主要イベント**
  - 村長から異変の調査を依頼される（報酬の提示）。
  - 情報屋「カラス」との会話 → 祠の場所と過去の噂を得る。
  - 旅の僧侶「ミレーユ」との出会い → 同行を申し出てくる。
- **想定されるプレイヤー行動**
  - 依頼を受ける／条件を交渉する。
  - カラスから情報を買う／脅して聞き出す（talk判定）。
  - ミレーユの同行を受け入れる／断る。
- **クリア条件**：依頼を受諾し、祠の場所を把握する（フラグ `quest_accepted`, `location_known`）。

### 第2章：遺跡への道中

- **章の目的**：祠まで無事にたどり着く。
- **主要イベント**
  - 森の中での遭遇（ならず者「ゴルツ」、または野生の獣）。
  - 道中の罠・天候（崩れかけの橋、急な霧）。
- **想定されるプレイヤー行動**
  - 敵と戦う（attack判定）／迂回して回避する（luck判定）。
  - ゴルツに遭遇した場合、戦う／話して味方に引き入れる（talk判定）。
- **分岐ポイント**：道中で**敵と戦うか、迂回するか**。ゴルツを仲間にできるかで以降の難易度が変わる。
- **クリア条件**：祠の入口に到達する（フラグ `reached_shrine`、任意で `gorz_ally`）。

### 第3章：遺跡内部の探索

- **章の目的**：祠の最奥へ進む手段を見つける。
- **主要イベント**
  - 罠の仕掛けられた広間（search / luck判定）。
  - 簡単な謎解き（壁の紋章を正しい順で押す等）。
  - 青白い光の正体に関する手がかりを発見。
- **想定されるプレイヤー行動**
  - 罠を探索・解除する。
  - 謎を解く／力ずくで突破を試みる。
  - 手がかりから祠の真相を推測する。
- **クリア条件**：最奥の扉を開ける（フラグ `inner_door_opened`）。

### 第4章：対決または交渉

- **章の目的**：異変の元凶と決着をつける。
- **真相**：祠の奥にいるのは、かつてこの地を守っていた精霊が、長い孤独と忘却で歪んでしまった姿。青白い光はその嘆き。
- **主要イベント**
  - 歪んだ精霊との対面。
  - **戦闘ルート**：精霊を打ち倒す（複数回のattack判定）。
  - **交渉ルート**：精霊の事情を聞き、鎮め方を見つけて説得する（talk判定／第3章の手がかり次第で有利）。
    - **成功補正**：第3章で精霊に関する手がかり（`clue_found`）を集めていれば説得の難易度が1段階下がり、ミレーユが同行（`mireille_ally`）していれば交渉判定に有利な修正がかかる。両方揃えば交渉ルートは大きく成功しやすくなる。
- **想定されるプレイヤー行動**
  - 戦って祠を鎮める。
  - 対話で精霊を慰め、安らかに眠らせる。
- **分岐ポイント**：**ボスと戦うか、交渉するか**。ミレーユ同行・手がかり収集の有無で交渉成功率が変わる。
- **クリア条件**：精霊を鎮める（フラグ `spirit_defeated` または `spirit_soothed`）。

### 第5章：結末 — 村への帰還

- **章の目的**：結果を村に持ち帰り、物語を締める。
- **主要イベント**
  - 村に戻り、村長へ報告。
  - 真実をどこまで話すかを選ぶ。
- **想定されるプレイヤー行動**
  - 村人に真実を語る／伏せる。
- **分岐ポイント**：**村のNPCにどこまで真実を話すか**。
- **エンディング（結果に応じて分岐）**
  - **成功（最良）**：交渉で精霊を鎮め、真実を語る → 村は祠を弔いの場として敬い、平穏が戻る。
  - **部分成功**：戦闘で鎮めた／真実を伏せた → 異変は止むが、どこか後味の残る結末。
  - **失敗**：精霊を鎮められなかった、または道中で大きく消耗した → 光は消えず、村に不安が残る（再挑戦の余地）。

---

## 5.5 主要な分岐の例（まとめ）

| 分岐 | 章 | 選択肢 | 影響 |
| --- | --- | --- | --- |
| 戦うか迂回するか | 第2章 | 戦闘 / 迂回・交渉 | ゴルツが仲間になるか。消耗度。 |
| 戦うか交渉するか | 第4章 | 戦闘 / 交渉 | エンディングの質。精霊の扱い。 |
| 真実をどこまで話すか | 第5章 | 全て話す / 伏せる | 村の反応・最終エンディング。 |

---

## 5.6 GM運用のための補足

- 各章は「クリア条件（フラグ）」を満たすと次章へ進む。フラグはシナリオ管理（[01-architecture.md](01-architecture.md) 参照）が保持する。
- 細部（村人の雑談、森の描写、罠の具体的な見た目など）はGMが即興で補完してよい。ただし**クリア条件と真相は変えない**。
- 登場NPC（カラス／ミレーユ／ゴルツ）の人格は [03-npc-templates.md](03-npc-templates.md) のテンプレートに従う。
- 判定が必要な行動は [04-d20-rules.md](04-d20-rules.md) の設計に従い、行動種別・使用ステータス・難易度を判定エンジンに渡す。

### 章ごとの想定判定（早見表）

| 章 | 代表的な判定 | action_type / used_stat / 難易度 |
| --- | --- | --- |
| 第1章 | 情報の聞き出し | talk / luck / normal |
| 第2章 | 戦闘・回避 | attack / attack / normal、回避は luck / hard |
| 第3章 | 罠探索・謎解き | search / luck / hard |
| 第4章 | 戦闘 or 説得 | attack / attack / hard、説得は talk / luck / normal〜hard |
| 第5章 | （判定原則なし。ロールプレイ中心） | — |
